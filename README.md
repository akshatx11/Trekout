# 🌍 TrekOut

**TrekOut** is a student-friendly travel and adventure web platform designed to help users explore destinations and discover trekking spots easily.

It provides a simple and clean interface where students and travel enthusiasts can browse locations, view details, and plan their trips without complexity. The platform focuses on making travel discovery affordable, accessible, and easy to use.

---

## 🚀 Features
- Explore budget-friendly travel destinations  
- Discover trekking spots  
- Easy-to-use and simple interface  
- Responsive design  

---

## 📌 Important Notes

- The bus search feature is currently not functional as this was our initial project.  
- To handle this, we implemented **quick routes** for easier ticket booking.  
- Student registration requires a **unique Student ID**.  
- The system prevents signup if the same Student ID is used again.  
- This project was built as a beginner-level application and may have some limitations.
